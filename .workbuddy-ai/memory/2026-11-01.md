# 2026-11-01

## 修复：大字版进入设置页先渲染小字版再闪成大字版

- 根因：`packageSettings/pages/settings/index.ts` 的 `data.elder` 初值写死 `false`，真正的值只在
  `onShow` 里 `await bootstrap()` + `await loadQuota()` 之后才 `setData`。而 wxml 用
  `wx:if="{{elder}}"` 整块换版式（两套完全不同的 DOM），所以第一帧必定是子女端小字版。
- `isElder()` 只读本地 storage 的 `modeOverride`，**不需要网络**，所以没必要等 bootstrap。
- 修复：`onLoad` 里先同步 `this.render()`；`data.elder` 初值改为 `isElder()`。
- 同类隐患仍在：`pages/home`、`pages/medicine`、`pages/weekly`、`pages/profile` 四个 tab 页
  都是「onShow 里 await 之后才 setData elder」，冷启第一次会闪（tab 实例常驻，切 tab 不重演）。
  正确写法参照 `pages/checkin/index.ts`（onLoad 里同步 `this.build()`）。
- 验证：`npx tsc --noEmit -p miniprogram/tsconfig.json` 通过。
