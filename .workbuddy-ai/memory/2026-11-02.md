## 全平台药品引用计数 → 「常用药」Top5 + 药名联想（P22）

**口径（主理人两次定稿，别再改回去）**
- 「引用次数」= **所有家庭**填写/使用这个药名的次数，**每次添加 +1、每次删除（归档）−1**，下限 0。
- 计数落库在 `medicine_usage_stats`（V008），按 `name_key` 归一（lower + 去首尾空白含全角空格）跨家庭唯一，
  **不存 family_id / openid / patient_id** —— 这张表本身不含可回指到个人的信息。
- 为什么单独一张表：引用次数是"跨家庭、按药名"的聚合，`medicines` 是"按家庭、按服药人"的行。
  在 `medicines` 上加计数列会让同一个药名在每个家庭各存一份互相矛盾的数，取全平台前 5 还得全表扫。
- 为什么不用内存 GROUP BY（第一版那么做过，被否）：跨家庭聚合拿不到别人的数据。
- 计数 SQL 必须单条原子：`INSERT … ON CONFLICT DO UPDATE SET use_count = use_count + 1`；
  减走 `UPDATE … SET use_count = GREATEST(use_count - 1, 0)`（减到不存在的药名不凭空造行）。
- 写入时机：**create 先计数再建药**（计数失败就当这次没建，避免"报错但药已存在"→ 重试重复占名额）；
  **archive 先归档再计数**（归档已生效，计数失败最多榜单偏高一次）。

**chips 的上榜门槛（重要，别当成 bug）**
- 自定义药名要净次数 ≥ 3（`MedicineUsage.MinCountToRank`）才进 chips；**平台预设名 ≥ 1 即可**。
- 预设豁免的理由：`medicines_common` 本来就是 `/api/medicine/common` 匿名公开的数据，出现不泄露新信息；
  否则上线头几个月 chips 永远是预设原序，看起来像功能没生效。
- 门槛挡的是：低流量期某个人手输的私密药名立刻出现在所有人首页，还能被轮询看出"刚有人加了这个药"。
- 不足 5 条用预设补位；输入联想（q 非空）不受门槛限制，只要 ≥1 就出。

**端点**
- `GET /api/medicine/suggest?fid=&q=`（契约表 v1.5）：`q` 空 = 全平台 Top5 + 预设补位；
  `q` 非空 = 本家庭历史（含已归档，按最近添加）→ 全平台榜 → 预设，去重后最多 8 条。
- 自家药排最前，因为全平台榜会被更热门的药占满，把"我妈在吃的那一个"挤到看不见。

**改动**
- `db/migrations/V008__medicine_usage_stats.sql`（新，已 apply 到本地容器）。
- `MedBox.Domain/MedicineUsage.cs`：Normalize / Matches / Merge（按组优先去重合并）/ 两个上限常量 / 门槛常量。
- `MedBox.Domain/Entities/MedicineUsageStat.cs`（新）。

  输入 debounce 220ms，回包校验 `step` + 当前输入，点选回填 药名/规格/剂量 并进第 2 步。
- `mock/index.ts` 用"active 同名行数"当计数（归档即 −1），`types/api.ts` 加 `MedicineSuggestItem`。

**Bug：ActionSheet 出现两个「取消」（已修）**

## 本地后端 E2E 回归（隔离库 medbox_e2e）

**关键坑（复用）**：`127.0.0.1:5432` 是 `wslrelay` = SSH 隧道→远端库（192.144.148.241）；
本地 docker 容器 `tigerrag-postgres-1` 发布在 `0.0.0.0:5432`。.NET 连 `127.0.0.1` 会打到远端，
要连本地容器必须用**主机 LAN IP**（如 `192.168.3.9:5432`）。容器密码在 `docker inspect` 的 POSTGRES_PASSWORD（`And@2088`），用户 tigerrag。

**跑法**：
1. `docker exec tigerrag-postgres-1 psql -U tigerrag -d postgres -c "CREATE DATABASE medbox_e2e"`
2. `CONTAINER=tigerrag-postgres-1 PGUSER=tigerrag DB=medbox_e2e bash db/apply.sh --allow-db medbox_e2e`（V001–V009 全过）
3. 播种 user/family/member/patient/medicine(remark)/plan
4. `dotnet build ... -p:OutputPath=/tmp/apibuild2/`，用 `ConnectionStrings__MedBox=Host=<LAN_IP>;Port=5432;Database=medbox_e2e;Username=tigerrag;Password=And@2088` + `JWT__SECRET=<32+>` + `Workers__Enabled=false` 起在 5099
5. 手工 HS256 签 JWT（sub=e2e_openid, iss=medbox, aud=medbox-mp），curl 带 `Authorization: Bearer`
