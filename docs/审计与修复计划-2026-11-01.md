## 六、已定决策（不再讨论）

| 决策 | 结论 | 理由 |
|---|---|---|
| 私钥是否重签 | **不重签** | 从未进入任何 commit，公开仓库无痕 |
| 证书文件放哪 | 原地保留 + `.gitignore` 挡死 | 搬目录要改一堆脚本引用，风险大于收益 |
| 真实 IP 怎么处理 | 文档里换占位符，真实值存 `README.local.md` | 公开仓库不能挂靶子 |
| `_daemon.json` | 内容并入 `deploy/README.md` §1，文件不提交 | 无脚本引用，但配置本身有价值 |
| `deploy/.env.example` 里的真实 AppID | 保留 | AppID 是公开标识，泄露不等于可冒用（需 AppSecret） |
| 服务器 SSH 加固 | **建议客户自行处理**（见下） | 属客户运维决策，不擅自动服务器 |

**给客户的服务器加固建议（未执行）**：22 端口对公网 + 密码登录 + `ubuntu` 直连，是最常见的被打入口。建议 ① 改 SSH 端口 ② 禁 root 密码登录、只留密钥 ③ 装 fail2ban ④ 口令换成 20 位以上随机串（原口令曾以明文存在本地文件里，可能被备份/同步带出）。
