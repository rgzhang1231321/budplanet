# 真机验收操作清单（M6 收口用）

> 用途：M6「真机验收与环境加固」最后四项只能在手机上验，本清单按顺序照做即可。
> 生成时间：2026-11-02　适用版本：当前 main（`44f14fb`）
> 预计用时：25–35 分钟（含订阅消息等待）

---

## 开工前：确认三件事（3 分钟）

| # | 检查什么 | 怎么查 | 看到什么算通过 |
|---|---|---|---|
| 0.1 | 云端接口活着 | 电脑浏览器打开 `https://api.apiyun.net/api/config/get` | 返回一段 `{"code":1001,...}` 或带 `data` 的 JSON（不是 502/超时）。`1001` 表示"未登录"，是正常的 |
| 0.2 | 服务器已配微信 AppSecret | 在服务器上执行 `grep -c "WX__SECRET=" deploy/.env` | 输出 `1`。若是 `0`，先填 AppSecret（小程序后台 → 开发管理 → 开发设置 → AppSecret），否则订阅消息发不出去，第 3 项必挂 |
| 0.3 | 手机已登录同一个微信号 | 手机微信 → 我 → 看是否为你本人的号（与开发者工具登录的号一致） | 一致。不一致会导致"家人看不到"，误判成 bug |

> ⚠️ 真机默认连**云端** `https://api.apiyun.net`，不是电脑上的本地服务 —— 所以手机上看到的是一套独立数据，跟开发者工具里的测试数据不互通，这是正常的。

---

## 第 1 项：真机完整走一遍（10 分钟）

**怎么开始**：开发者工具点右上角「预览」→ 生成二维码 → 手机微信扫码打开。

| 步 | 做什么 | 看到什么算成功 |
|---|---|---|
| 1.1 | 扫码打开，等首屏出现 | 直接进「你是哪种情况」页（不是欢迎页），页面上有《隐私政策》《用户协议》链接和"本工具仅提供提醒"的注记 |
| 1.2 | 点「我帮家人看着」 | 弹出免责确认，两个勾选框都要手动勾，确认按钮要等约 1 秒才可点（防误点） |
| 1.3 | 勾完点确认 | 进首页，不报错。若弹权限框（通知/相册等）按需要允许 |
| 1.4 | 设置 → 添加服药人，填「张建国」，称呼填「爸爸」 | 列表里出现「爸爸 · 张建国」 |
| 1.5 | 添加药品：药名「二甲双胍」，规格**故意留空**，剂量选「1片」，时间选一个**两三分钟后**的时间点 | 保存成功，不报"服务异常"（这是今天刚修的问题，重点验） |
| 1.6 | 等到那个时间点，看是否收到订阅消息 | **见第 3 项**（需要先授权） |
| 1.7 | 回到首页，等时间到，点这条记录打卡「我已服用」 | 状态变"已服用"，页面出「撤销」入口，3 秒后消失 |
| 1.8 | 切到老人端（设置里切"我自己吃"或用老人身份打开） | 字明显变大，按钮变大，一屏最多 4 个元素 |
| 1.9 | 老人端点打卡 | 直接变已服用，**没有**撤销（这是设计） |
| 1.10 | 回子女端看板 | 能看到刚才那条已服用记录（家人可见） |

**通过标准**：1.1–1.10 全程无红色报错弹窗、无"服务异常"、无白屏。

## 第 2 项：老人端实地体验（5 分钟）

| 步 | 做什么 | 看到什么算成功 |
|---|---|---|
| 2.1 | 老人端首页，把手机拿远一点看 | 正文和按钮都看得清，不用凑近 |
| 2.2 | 手指粗按打卡按钮（故意按偏一点） | 仍能点中（按钮高 160rpx ≈ 手机上半厘米多） |
| 2.3 | 找一条已过时间没打卡的记录 | 显示「待服」，**不出现**"漏服""失败""错误" |
| 2.4 | 横向滑动页面 | 页面不会左右晃动（无横向溢出） |

**通过标准**：2.1–2.4 全部符合。任何一处出现小字/漏服字样/横向晃动，记下来。

## 第 3 项：订阅消息真实到达（5 分钟 + 等待）

> 前提：0.2 已配好 AppSecret。

| 步 | 做什么 | 看到什么算成功 |
|---|---|---|
| 3.1 | 在设置里找到「提醒授权」，点开关 | 弹出微信授权框，勾选后确认（**这一步必须真点，否则后面收不到消息**） |
| 3.2 | 设一个 3 分钟后到点的药，锁屏等待 | 到点收到微信「服务通知」，点开能跳回小程序 |
| 3.3 | 到点后**不打**，等过时间 | 收到"漏服提醒"类消息（模板语义见下方备注） |
| 3.4 | 打满一周数据后看周报消息 | 收到周报提醒 |

**通过标准**：3.2 必过（打卡提醒）。3.3/3.4 收到更好；收不到先记下 errcode，不要现场改代码。

> ⚠️ **已知待确认项（F13）**：现在用的三个模板是「药剂更换提醒 / 工作任务待办 / 周报更新提醒」，其中"漏服提醒"借的是"工作任务待办"模板，审核可能被判"模板与用途不符"。这一条已登记为**提审前必查**，真机若收到但文案看着别扭，属已知问题，不用当 bug 记。

## 第 4 项：弱网与断网（5 分钟）

| 步 | 做什么 | 看到什么算成功 |
|---|---|---|
| 4.1 | 手机开**飞行模式** | — |
| 4.2 | 点一条药的「我已服用」 | 页面**立刻**变已服用（不等网络），底部出现「未同步/待同步」类提示 |
| 4.3 | 关飞行模式，等 10 秒 | 提示变「已同步」，不点任何按钮 |
| 4.4 | 断网状态下打卡后，**立刻杀掉小程序**，再重进 | 打卡不丢（重进后仍是已服用或自动补同步） |
| 4.5 | 断网超过 1 分钟再恢复 | 若最终同步失败，记录必须**回到"待服"**、且能重新打卡（不能假显示已服） |

**通过标准**：4.2/4.3 必过；4.4/4.5 是今天刚修的边界（`da5ecfc`），重点验。

## 第 5 项：复诊报告存相册（3 分钟）

| 步 | 做什么 | 看到什么算成功 |
|---|---|---|
| 5.1 | 我的 → 用药报告（或复诊报告） | 报告页正常显示，三个数字和药品表格完整，右侧文字不被截断 |
| 5.2 | 点「保存为图片」，首次会弹相册权限 | 允许 |
| 5.3 | 等 2 秒 | 出现「已存到相册」提示；按钮恢复可再点 |

**通过标准**：5.3 不得卡在"生成中"（这是今天修的 `44f14fb`，重点验）；5.4 图片不是空白/缺内容。
